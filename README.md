# 🚀 Galaxy Strike

A fun space shooting game created as a Python project. 🎮

## 🎮 About the Game

Galaxy Strike is a simple shooting game where the player controls a spaceship, fights enemies, and tries to achieve a high score.

## ✨ Features

- 🚀 Player spaceship
- 👾 Enemy targets
- 🔫 Shooting system
- 💥 Collision system
- 🏆 Score tracking
- 🎮 Interactive gameplay

## 🛠️ Technologies Used

- Python
- Pygame

## ▶️ How to Run

1. Install Python.
2. Install Pygame:
   `pip install pygame`
3. Run `GALAXY_STRIKE.py`
