# 🚀 Galaxy Strike

A fun and interactive space shooting game created as a Python project. 🎮

## 🎮 About the Game

Galaxy Strike is a simple shooting game where the player controls a spaceship, fights enemies, and tries to achieve a high score.

## ✨ Features

- 🚀 Player spaceship
- 👾 Enemy targets
- 🔫 Shooting system
- 💥 Collision system
- 🏆 Score tracking
- 🎮 Interactive gameplay

## 🛠️ Technology Used

- Python

## 📚 What I Learned

- Python programming
- Game logic
- Keyboard controls
- Collision detection
- Score management
